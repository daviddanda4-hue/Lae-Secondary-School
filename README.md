# Lae Secondary School Website

This project is a static website for Lae Secondary School in Morobe Province, Papua New Guinea.

## Pages

- `index.html` - Home page and cover page
- `about.html` - School information and leadership
- `programme.html` - Academic programmes and extracurricular activities
- `information.html` - Admissions, calendar, and school policies
- `contact.html` - Contact form and school address

## Images

The website images are stored in the `Images` folder:

- `Image 1.jpg` - Home page cover image
- `Image 2.jpg` - Website background image
- `Image 3.webp` - About page image

Keep the `Images` folder in the same directory as the HTML files so the images display correctly.
